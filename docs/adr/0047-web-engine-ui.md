## コンテキスト

- E3: UI には常に「AIキャラクター」バッジを表示する（サクラサイト商法との区別）。
- E8 のため DM の返答をストリーミングで受け取る（[ADR-0037](0037-chat-streaming-sse.md)）。E6 の安全対応の返答には相談窓口を出す（[ADR-0043](0043-safety-e6-and-output-guard.md)）。
- 自発メッセージは DM の履歴に通常のメッセージとして残り、プッシュ通知は無く未読で表示する（P6）。ユーザーが停止・送らない時間帯を設定できる（E4）。
- メモリパネルで記憶の種類・置き換えられた履歴・約束を扱う（M11・E5）。キャラの状況を DM に出す（C5）。好感度はどこにも見せない（A11）。
- Instagram の見た目の再現（[ADR-0021](0021-web-ui-implementation.md)）と、アクセシビリティの約束（[ADR-0031](0031-web-ui-accessibility-and-dev-only-pages.md)）は保つ。

## 決定

### 「AIキャラクター」バッジ（E3）

- キャラの名前・ハンドルの横に紫の小さな丸いバッジ「✦ AIキャラクター」（`<AiBadge />`）。出す場所: フィード・投稿詳細のカードのヘッダー、キャラのコメント、プロフィール、
  検索結果、DM 一覧の行とおすすめ、DM ヘッダー、会話の先頭のプロフィール。ストーリーズはアバターの下端に小さな「AI」（`variant="compact"`。Instagram の LIVE の表示に倣う。
  読み上げは「AIキャラクター」）。
- 色はトークン `--ig-ai-badge-bg` / `--ig-ai-badge-text`（文字のコントラストはライト 6.3:1・ダーク 7.6:1）。幅が足りないときは名前の方を省略する（バッジは縮めない）。
- 読み上げのラベルを上書きしているリンクは、ラベルにも「AIキャラクター」を入れる。

### DM の送信（ストリーミング）

- `api.streamChat`: `fetch` の本文を `ReadableStream` で読み、SSE を逐次組み立てる（`lib/api/sse.ts`。EventSource は POST と `Authorization` を送れない）。
  タイムアウトは接続から `done` まで 45 秒の 1 つだけ（`CHAT_STREAM_TIMEOUT_MS`。途中の無通信のタイムアウトは設けない。サーバーのキープアライブがある）。
- ストリーミングを使えない環境・`/chat/stream` が 404 / 405 の API では `POST /chat` にフォールバックし、そのセッションでは以後 `/chat` を使う。
- 表示: 送信の 400 ms 後から「入力中…」。最初の文字は送信から 1 秒後まで待って出す（「入力中…」を最低 600 ms 見せる）。`delta` で吹き出しが伸び、`replace` で本文を差し替え、
  `done` で保存済みのメッセージに同じ key のまま置き換える（ちらつかない）。返答が流れ始めたら自分の吹き出しを送信済みにする。
  受信中に Realtime で届いた同じメッセージは `done` まで隠し、重複させない。
- `error` を受けたら受信中の吹き出しを消し、自分の吹き出しを「送信できませんでした・タップで再送」にしてトーストを出す（サーバーは何も保存していない）。
- 画面を離れても送信は続き、戻ると受信中の返答を表示する。

### 相談窓口のカード（E6）

- 安全対応をした返答（`messages.safety_triggered = true`。受信中は `replace` の `reason: "safety"`）の下に、**キャラの吹き出しではなく横幅いっぱいのアプリのカード** を出す。
  電話番号は `tel:` のボタン、受付時間、ウェブサイト（別のタブ）、最後に「命に関わるときは 119 番」の固定の行。**閉じる操作は置かない**（会話を開くたびに同じ返答の下に出る）。
- 窓口の一覧は `GET /safety/resources`（返答を受け取った端末では `ChatResponse.safety.resources` を先にキャッシュに入れる）。一覧を読み込めなくても、119 番の行と返答の本文の窓口は出る。
- 印はサーバーの行にあるので、履歴の読み込み・別の端末でも出る（端末に覚える方式はやめた）。

### 自発メッセージ（P6・E4）

- 通常の吹き出しと同じ表示にし、DM 一覧では未読にする。**返信を急かす特別な印・強調はしない**（圧をかけない）。
- 設定: `/me` の「キャラからのメッセージ」に全体のオン・オフと送らない時間帯（開始・終了。日本時間の時。既定 0〜7 時。日をまたぐ場合は「翌」、同じ時刻なら制限なし）と説明。
  キャラごとのオン・オフは DM の「i」のパネルの先頭（全体がオフのときは説明付きで無効）。変更はすぐに画面に反映し、保存に失敗したらその項目だけを戻す。

### メモリパネル（M11・E5）

- 種類（事実・好み・出来事・約束・予定・気持ち・ふたりの関係・会話の要約）のチップと絞り込み（その会話にある種類だけを出す）。追加・編集で種類を選べる（要約は選べない）。
- 「以前の記憶」: 置き換えられた記憶（`include_superseded=true` で 1 回の取得）を読み取り専用で出し、「新しい記憶に置き換わりました」と今の記憶を添える。
- 削除の確認ダイアログで「自動では覚え直さない」ことを伝える（[ADR-0039](0039-user-edited-memory-protection.md)）。
- 「約束・予定」: 近い順の予定 → 期日の無いもの → 期日を過ぎたもの。日本時間の相対的な言い方（今日・明日・3 日後・来週・来月）。「完了」は確認なし、「取り消し」は確認する。
- 「〇〇があなたのことを覚えました」は、Realtime の `memories` の INSERT（そのキャラの分。要約とユーザーが追加した記憶は除く）で出す（記憶は返答の後に非同期で作られる）。
  返答の後の分析は会話がまとまってから行う（`ENGINE_POST_TURN_DELAY_SECONDS` = 180 秒のデバウンス。[ADR-0046](0046-engine-cost-and-latency.md)）ので、通知は**会話が止まって約 3 分後**
  （話し続ければ後ろへずれ、最大 18 分）で、返答の直後には出ない。購読は DM の画面にあるので、それまでに画面を離れると通知は出ない（記憶はメモリパネルに入る）。

### DM ヘッダーの状況（C5）と好感度（A11）

- 名前の下の行に `character_states.status_label`（「仕事中」「カフェでひと休み」など）。行・ラベルが無ければ「アクティブ」。読み込み中は空にする
  （「アクティブ」→「仕事中」と切り替わって見えないように）。DM の先読みで一緒に取り（[ADR-0030](0030-web-data-fetching-dm-and-prefetch.md) の追補）、画面を開いている間は 2 分ごとと復帰時に取り直す。
  忙しさ（`busyness`）が 2 以上ならアバターの緑の点を出さない。
- **好感度の数値・関係の段階はどこにも表示しない**（[ADR-0041](0041-affinity-engine.md)）。

### テスト

- E2E `engine.spec.ts`（バッジ・ストリーミングの表示・エラー・相談窓口のカード・自発メッセージの設定・メモリパネル）。ストリーミング・エラー・カードの UI のテストは
  `/chat/stream` の応答を差し替えて行う（ヘッドレスの Chromium ではストリームの本文を少しずつ読めないため、順に伸びる表示は単体テストとスクリーンショットで確認）。
  スクリーンショットの 23〜26 がエンジンの画面。

## 結果・トレードオフ

- キャラが出るすべての画面で AI であることが分かる。名前の横の幅を使うので、長い名前は省略されやすくなる。
- 返答が文ごとに現れる。1 秒の下限は、サーバーが速すぎる場合にだけ最初の文字を遅らせる（実際の LLM ではふつう影響しない）。
- 相談窓口のカードは閉じられないので、その返答の下に出続ける（意図した挙動）。119 番の行は Web に固定で書いているので、窓口の YAML と一緒に内容を確認する。
- 自発メッセージに印を付けないので、ユーザーは返答と自発メッセージを見た目で区別できない（DM の履歴として自然に読める）。

## 代替案

- **バッジを名前の代わりにアイコンだけにする**: 意味が伝わらない（「AIキャラクター」と文字で書く）。
- **EventSource で受信する**: POST と `Authorization` を送れない（[ADR-0037](0037-chat-streaming-sse.md)）。
- **ストリームに無通信のタイムアウトを別に設ける**: サーバーはキープアライブを送り、生成が締め切り（`CHAT_DEADLINE_SECONDS`、既定 38 秒）を過ぎたら `error` を返すので、全体の 45 秒の 1 つで足りる。
- **相談窓口をキャラの吹き出しの中に出す・閉じられるカードにする**: キャラの発言と区別しにくい・うっかり閉じて見失う。
- **自発メッセージに「キャラから」の印やバッジを付ける**: 返信を急かす圧になる。
- **状況の行に好感度の段階を出す**: A11 に反する。
