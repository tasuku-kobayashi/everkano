# ADR-0024: ユーザー × キャラあたりの記憶の上限（MEMORY_MAX_PER_CHARACTER）と自動記憶の入れ替え

- ステータス: 採用（自動記憶の入れ替えで置き換えられた記憶（履歴）を先にすることを [ADR-0038](0038-memory-engine-v2.md) で追補）
- 日付: 2026-09-25
- 関連: 仕様書 §9 / [ADR-0005](0005-vector-index-and-exact-memory-search.md)・[ADR-0009](0009-memory-engine.md)（本 ADR で追補）・[ADR-0018](0018-in-process-rate-limit.md) /
  実装: `apps/api/app/services/memory_capacity.py`, `apps/api/app/services/memory.py`（`save_candidates` / 要約）, `apps/api/app/services/user_memories.py`,
  `apps/api/tests/integration/test_memory_limits_and_summary.py`

## コンテキスト

- `/chat` の長期記憶の検索は、(user, character) のペアの全件との距離を計算する厳密検索（ADR-0005）。コストは件数に比例する。
- 記憶の件数に上限が無く、メモリパネルの追加（`POST /memories`）にもレート制限が無かったため、1 人のユーザーがペアの記憶を数万件に
  増やし、以後の自分の DM を遅くする（プロセス・DB を占有して他のユーザーにも影響する）ことができた。`POST /memories` は 1 件ごとに
  埋め込み API も呼ぶので、費用の面でも乱用できた。
- 長く使い続けると、自動抽出と中期要約だけでもペアの記憶は増え続ける。

## 決定

- ペアあたりの上限 `MEMORY_MAX_PER_CHARACTER`（既定 500、10〜100000）を設ける。
- **ユーザーの追加**（`POST /memories`）: 上限に達していたら 422 `validation_error`
  （「覚えておける記憶は1人のキャラクターにつき500件までです…」）。どれを消すかはユーザーが選ぶ（自動で消さない）。
- **自動抽出・中期要約**: 自動で作られた記憶のうち、重要度が最も低く古いもの（`is_user_edited` と `summary` タグを除く）を入れ替える。
  1 回の追加で削除するのは最大 5 件（運用で上限を下げた直後に、既存の記憶を一度に大量に消さない）。入れ替えられる記憶が無ければ、
  自動抽出は保存を見送る（WARNING ログ）。要約は上限を超えても保存する。入れ替えで削除した記憶は audit `memory.delete`
  （`source=capacity_eviction`・`capacity`）に残し、ユーザーの削除と区別できるようにする。
- 同じペアへの同時の追加で上限を超えないよう、トランザクション内でペア単位のアドバイザリーロック
  （`pg_advisory_xact_lock(hashtextextended(user_id || ':' || character_id))`）を取ってから数え直す。
- `POST` / `PATCH /memories`（埋め込み API を呼ぶ）にユーザー単位のレート制限 `RATE_LIMIT_MEMORIES_PER_MINUTE`（既定 30 / 分）を設ける
  （超過は 429 `rate_limited` + `Retry-After`）。

## 結果・トレードオフ

- 1 ペアの厳密検索の件数が上限で抑えられ、`/chat` の遅延の上限が見積もれる（500 件 × 1536 次元の距離計算）。
- 上限に達したペアでは、重要度の低い自動記憶から忘れていく。ユーザーが追加・編集した記憶と要約は自動では消えない。
- ユーザーが上限まで自分で追加した場合、自動抽出は何も保存できなくなる（ログで検知できる）。メモリパネルで不要な記憶を消してもらう。
- 既定値 500 は MVP の想定（1 日数十往復 × 数か月）での目安。変更は環境変数だけで行える（下げた場合、超過分は自動記憶が追加されるたびに
  少しずつ減る）。

## 代替案

- **上限を設けず、HNSW で近似検索する**: ペアで絞った近似検索は取りこぼす（ADR-0005）。件数が増えても厳密検索のまま遅延を抑える方を選んだ。
- **上限に達したらユーザーの追加も古いものから自動で消す**: ユーザーが残したい記憶を黙って消すことになる。
- **自動抽出の記憶を期限で消す**: 重要度の高い記憶まで時間で消える。重要度と古さで入れ替える方が、キャラが覚えている内容の質を保てる。
