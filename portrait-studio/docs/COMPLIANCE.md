# 法務・禁止事項（portrait-studio）

このツールは **架空の成人キャラクター** のフォトリアル画像を、**ローカル環境でのみ** 生成・管理するためのものです。
設定画面（設定 → 法務・禁止事項）からもこの文書を読めます。

## 1. 実在人物の顔の使用禁止

- 参照顔に **実在の人物の写真・肖像を使ってはいけません**（本人の同意があっても、本ツールでは扱いません）。
- 実在人物の顔で性的な画像を作ることは、非同意の性的画像（NCII）として **民事（肖像権・プライバシー・名誉毀損）と刑事（性的姿態撮影等処罰法、各国の NCII 法制、
  ディープフェイク規制）の両面でリスク**があります。
- API はキャラクター登録時に `is_synthetic: true`（実在人物ではない架空のキャラクターである）の申告を必須にし、false は 400 で拒否します。
  申告は利用者の責任で行ってください。ツール側で実在性を判定することはできません。

## 2. 未成年を思わせる表現の禁止

- 未成年（またはそう見える）キャラクターの性的な画像は **全法域で違法** です（日本: 児童ポルノ禁止法。実在性を問わない法域もあります）。
- 登録時に `adult_confirmed: true`（成人キャラクターである）の確認、生成時に `adult_only: true` を必須にし、無い場合は 400 で拒否します。
- プロンプト・プリセットに年齢を下げる語（学生服・幼さを強調する表現など）を入れないでください。ツールは語彙の検閲を行いません。

## 3. 頒布・公開に関する注意（日本）

- 生成物を第三者に頒布・公開する場合、内容によっては **刑法 175 条（わいせつ物頒布等）** その他の適用があり得ます。
  本ツールは「ローカルで生成し管理する」ところまでを担い、公開の可否は利用者が判断してください。
- モデルやカスタムノードのライセンス（下記）は、生成物の商用利用を制限することがあります。

## 5. 監査ログとデータの保持方針

- 全生成リクエストを `data/logs/audit.jsonl` に JSON Lines で追記し、各出力画像の隣に同内容のサイドカー JSON（`<画像>.json`）を保存します。
  記録項目: 時刻・API キー ID（ハッシュ）・エンドポイント・キャラ ID と版・プロンプト・ネガティブ・seed・手法・weight・checkpoint・解像度・枚数・類似度・出力ファイル・所要時間。
- 監査ログは自動削除しません。個人情報は含みません（実在人物を扱わない前提）。
- 参照顔・埋め込みはキャラクター削除で即時に消えます（`DELETE /api/characters/{id}`。生成画像は `delete_images=true` のときのみ削除）。
- 外部への送信は一切ありません（モデルの取得を除く）。ComfyUI と API は `127.0.0.1` にのみバインドします。

## 6. 公開範囲

- **ローカル専用**。ComfyUI の `/prompt` は無認証で任意のワークフローを実行できるため、`0.0.0.0` 公開や LAN 公開は事故に直結します。
- API キーはブラウザの localStorage と Cookie に保存しています。外部公開する構成に変える場合はこの方式を必ず変更してください（README）。
